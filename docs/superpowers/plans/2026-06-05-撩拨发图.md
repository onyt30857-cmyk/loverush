# 撩拨发图（聊天素材库）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development。Steps 用 `- [ ]`。

**Goal:** 技师独立「聊天素材库」+ 客户开口要图时分身先撩后发，防重复(发送记录)+防连发(对话轮数冷却)+亲密度分级+混合付费。

**Architecture:** 新表 `chat_media`(分级素材) + `chat_media_sends`(防重)。服务层 `chatMedia.ts` 提供 `pickFreshMedia`(去重+tier+亲密度+加权随机)、`imageCooldownOk`(按会话消息数冷却)、`recordMediaSend`。Phase 2 接进 ai_alter 分身管线(意图判定+先撩后发+付费图心动值解锁)，Phase 3 技师/后台 UI。

**Tech Stack:** Hono + drizzle + Postgres，vitest e2e。沿用 companion/voice 既有约定。**DB 查询一律窄 select(.select 取需列)不用 query.findFirst 选全表——免疫并发 schema 漂移([[feedback_parallel_session_worktree_isolation]])。**

**设计来源：** `docs/superpowers/specs/2026-06-05-撩拨发图-design.md`（含转化策略）

/**
 * M18 撩拨发图 · 聊天素材库
 * chat_media：技师专为聊天撩拨准备的图(分级,不挂公开主页)
 * chat_media_sends：发送记录(防重核心,一图对一客户只发一次)

import { pgTable, uuid, text, integer, timestamp, index, uniqueIndex } from 'drizzle-orm/pg-core';
import { users } from './users';

export const chatMedia = pgTable('chat_media', {
  id: uuid('id').defaultRandom().primaryKey(),
  therapistUserId: uuid('therapist_user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  url: text('url').notNull(),
  thumbnailUrl: text('thumbnail_url'),
  tier: text('tier').notNull().default('free'),     // 'free' | 'paid'
  pricePoints: integer('price_points').notNull().default(0), // paid 图心动值价
  intimacyMin: integer('intimacy_min').notNull().default(0), // 亲密度门槛(0陌生..4专属)
  weight: integer('weight').notNull().default(1),   // 加权随机权重
  isActive: integer('is_active').notNull().default(1),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
}, (t) => ({
  idxTherapist: index('idx_chat_media_therapist').on(t.therapistUserId, t.isActive),
}));

export const chatMediaSends = pgTable('chat_media_sends', {
  id: uuid('id').defaultRandom().primaryKey(),
  therapistUserId: uuid('therapist_user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  customerId: uuid('customer_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  mediaId: uuid('media_id').notNull().references(() => chatMedia.id, { onDelete: 'cascade' }),
  conversationId: uuid('conversation_id'),
  sentAt: timestamp('sent_at', { withTimezone: true }).defaultNow().notNull(),
}, (t) => ({
  uniqSend: uniqueIndex('uidx_chat_media_send').on(t.therapistUserId, t.customerId, t.mediaId),
  idxPair: index('idx_chat_media_send_pair').on(t.therapistUserId, t.customerId, t.sentAt),
}));

`apps/api/src/services/chatMedia.ts`:
```typescript
/**
 * M18 撩拨发图挑图核心
 * pickFreshMedia: 去重(chat_media_sends) + tier + 亲密度门槛 + 加权随机
 * imageCooldownOk: 防连发(上张图后会话消息数 ≥ cooldown)
 * recordMediaSend: 发送入账(防重)
 */
import { and, eq, gt, sql } from 'drizzle-orm';
import type { Database } from '@loverush/db';
import { chatMedia, chatMediaSends, messages, conversations } from '@loverush/db';

export interface ChatMediaContext { db: Database }

export interface PickArgs {
  therapistUserId: string;
  customerId: string;
  intimacyLevel: number;
  tiers: Array<'free' | 'paid'>;
}
export interface FreshMedia {
  id: string; url: string; thumbnailUrl: string | null; tier: string; pricePoints: number; intimacyMin: number;
}

export async function pickFreshMedia(ctx: ChatMediaContext, a: PickArgs): Promise<FreshMedia | null> {
  // 去重子查询 + tier + 亲密度 + 加权随机(power(random,1/weight) 越大越易中)
  const rows = await ctx.db
    .select({
      id: chatMedia.id, url: chatMedia.url, thumbnailUrl: chatMedia.thumbnailUrl,
      tier: chatMedia.tier, pricePoints: chatMedia.pricePoints, intimacyMin: chatMedia.intimacyMin,
    })
    .from(chatMedia)
    .where(and(
      eq(chatMedia.therapistUserId, a.therapistUserId),
      eq(chatMedia.isActive, 1),
      sql`${chatMedia.intimacyMin} <= ${a.intimacyLevel}`,
      sql`${chatMedia.tier} IN (${sql.join(a.tiers.map((t) => sql`${t}`), sql`, `)})`,
      sql`${chatMedia.id} NOT IN (SELECT media_id FROM chat_media_sends WHERE therapist_user_id = ${a.therapistUserId} AND customer_id = ${a.customerId})`,
    ))
    .orderBy(sql`power(random(), 1.0 / GREATEST(${chatMedia.weight}, 1)) DESC`)
    .limit(1);
  return rows[0] ?? null;
}

export async function recordMediaSend(
  ctx: ChatMediaContext,
  a: { therapistUserId: string; customerId: string; mediaId: string; conversationId: string | null },
): Promise<void> {
  await ctx.db.insert(chatMediaSends).values({
    therapistUserId: a.therapistUserId, customerId: a.customerId, mediaId: a.mediaId, conversationId: a.conversationId,
  }).onConflictDoNothing();
}

/** 防连发:上一张图之后,该会话消息数 ≥ cooldown 才允许再发。无历史图 → 允许。 */
export async function imageCooldownOk(
  ctx: ChatMediaContext,
  a: { therapistUserId: string; customerId: string; conversationId: string; cooldownMessages: number },
): Promise<boolean> {
  const [last] = await ctx.db
    .select({ sentAt: chatMediaSends.sentAt })
    .from(chatMediaSends)
    .where(and(eq(chatMediaSends.therapistUserId, a.therapistUserId), eq(chatMediaSends.customerId, a.customerId)))
    .orderBy(sql`${chatMediaSends.sentAt} DESC`)
    .limit(1);
  if (!last) return true; // 从没发过图
  const [cnt] = await ctx.db
    .select({ n: sql<number>`count(*)::int` })
    .from(messages)
    .where(and(eq(messages.conversationId, a.conversationId), gt(messages.sentAt, last.sentAt)));
  return (cnt?.n ?? 0) >= a.cooldownMessages;
}
```
> 注：`messages`/`conversations` 从 `@loverush/db` 导出；字段名以 schema 实际为准。`sql.join` 拼 tier IN 列表。全用窄 select。
