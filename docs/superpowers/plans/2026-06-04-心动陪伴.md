# 心动陪伴（陪聊付费）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给为爱冲锋技师服务新增"陪聊付费"：日常闲聊免费（跑 T2 廉价模型），客户显式发起的"亲密动作"消耗心动值（付费动作跑 T1，技师分成），关系靠亲密度升温。

**Architecture:** 复用现有积分钱包（`points.ts` 原子 debit/credit）做心动值账本（metadata.scene='companion'），新增 `companion_actions`（动作目录·价格/分成配置驱动）+ `intimacy`（客户×技师亲密度）两张表。分身回复在 `ai_alter.ts` 按场景分层选模型：免费闲聊 T2、付费动作 T1。所有业务数值（定价/分成/新人券）存表由 seed/admin 设，代码不硬编码。

**Tech Stack:** Hono + drizzle-orm + Postgres，vitest e2e（进程内 Hono + 本地 test PG），bun 运行迁移脚本。沿用 `apps/api/src/services` + `routes` + `packages/db/src/schema` 既有约定。

**设计来源：** `docs/superpowers/specs/2026-06-04-心动陪伴-design.md`

## 阶段总览（每阶段独立可交付可测）

- **Phase 1（本计划详写）· 计费主干**：心动值账本（复用 points）+ `companion_actions`/`intimacy` 表 + 一个动作端到端（发起→扣心动值→技师分成→亲密度+exp）+ 免费闲聊降 T2。产出：后端能完整跑通"付费一次亲密动作"的闭环，e2e 绿。
- **Phase 2 · 亲密度系统 + 动作矩阵**：等级阈值/态度切换（喂分身 prompt）、其余动作（叫醒哄睡/今夜专属/看看她/撩拨）、新人体验券。→ 展开为 `2026-XX-心动陪伴-P2.md`。
- **Phase 3 · 前端**：聊天页亲密度 ribbon（C）+ 流内付费壳（A）+ 语音悄悄话气泡（B）+ 充值心动值包页。→ 独立计划。
- **Phase 4 · 降本与风控**：半模板高频开场、主动触达限频、白嫖软收口、T2 露馅 A/B 自测、分成入账对账。→ 独立计划。

> 本计划只详写 Phase 1。Phase 2-4 到达时各自用 writing-plans 展开（避免一次性巨型计划 + 业务数值未定时的占位）。

```typescript
/**
 * M18 心动陪伴（陪聊付费）
 *
 * companion_actions：亲密动作目录 · 价格/分成配置驱动（seed/admin 设值，代码不硬编码）
 * intimacy：客户 × 技师 亲密度 · 经验值累积 → 等级
 */
import { pgTable, uuid, text, integer, timestamp, index, primaryKey } from 'drizzle-orm/pg-core';
import { users } from './users';

export const companionActions = pgTable('companion_actions', {
  code: text('code').primaryKey(),                 // 'voice_whisper' / 'wake_up' / 'tonight_exclusive' ...
  actionType: text('action_type').notNull(),       // 'voice' | 'media' | 'mode' | 'exclusive'
  pricePoints: integer('price_points').notNull(),  // 心动值价（积分单位）
  revenueShareBps: integer('revenue_share_bps').notNull().default(7000), // 技师分成 · 1000=10%
  expReward: integer('exp_reward').notNull().default(10),                // 发起一次给的亲密度经验
  isActive: integer('is_active').notNull().default(1),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
});

export const intimacy = pgTable(
  'intimacy',
  {
    customerId: uuid('customer_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    therapistUserId: uuid('therapist_user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    exp: integer('exp').notNull().default(0),     // 累积经验值
    level: integer('level').notNull().default(0), // 0 陌生 1 熟悉 2 暧昧 3 心动 4 专属（Phase 2 定阈值）
    updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
    createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
  },
  (t) => ({
    pk: primaryKey({ columns: [t.customerId, t.therapistUserId] }),
    idxTherapist: index('idx_intimacy_therapist').on(t.therapistUserId),
  }),
);
```

`apps/api/src/services/companion.ts`:
```typescript
/**
 * M18 心动陪伴 service
 * triggerCompanionAction：发起亲密动作 → 扣客户心动值（points debit, scene=companion）
 *   → 技师分成（credit revenueShareBps）→ 亲密度 +exp。平台留存=差额（隐式平台收入）。
 */
import { and, eq, sql } from 'drizzle-orm';
import { companionActions, intimacy } from '@loverush/db';
import type { Database } from '@loverush/db';
import { HttpError, ErrorCode } from '../errors';
import { debit, credit } from './points';

export interface CompanionContext { db: Database }

export async function triggerCompanionAction(
  ctx: CompanionContext,
  args: { customerId: string; therapistUserId: string; actionCode: string },
): Promise<{ action: string; pricePoints: number; intimacyExp: number }> {
  const action = await ctx.db.query.companionActions.findFirst({
    where: and(eq(companionActions.code, args.actionCode), eq(companionActions.isActive, 1)),
  });
  if (!action) throw HttpError.badRequest(ErrorCode.E1002_NOT_FOUND, 'companion action not found');

  const idem = `companion.${args.customerId}.${args.therapistUserId}.${args.actionCode}.${Date.now()}`;

  // 1) 扣客户心动值（余额不足 debit 内抛 E2010）
  await debit(ctx, {
    userId: args.customerId,
    amount: action.pricePoints,
    txnType: 'companion_spend',
    description: `心动陪伴 · ${args.actionCode}`,
    metadata: { scene: 'companion', actionCode: args.actionCode, therapistUserId: args.therapistUserId },
    idempotencyKey: idem,
  } as never);

  // 2) 技师分成
  const therapistShare = Math.floor((action.pricePoints * action.revenueShareBps) / 10000);
  if (therapistShare > 0) {
    await credit(ctx, {
      userId: args.therapistUserId,
      amount: therapistShare,
      txnType: 'companion_earn',
      description: `心动陪伴分成 · ${args.actionCode}`,
      metadata: { scene: 'companion', actionCode: args.actionCode, customerId: args.customerId },
      idempotencyKey: `${idem}.share`,
    } as never);
  }

  // 3) 亲密度 +exp（upsert）
  await ctx.db
    .insert(intimacy)
    .values({ customerId: args.customerId, therapistUserId: args.therapistUserId, exp: action.expReward })
    .onConflictDoUpdate({
      target: [intimacy.customerId, intimacy.therapistUserId],
      set: { exp: sql`${intimacy.exp} + ${action.expReward}`, updatedAt: new Date() },
    });

  return { action: args.actionCode, pricePoints: action.pricePoints, intimacyExp: action.expReward };
}

export async function getIntimacy(
  ctx: CompanionContext,
  args: { customerId: string; therapistUserId: string },
) {
  const row = await ctx.db.query.intimacy.findFirst({
    where: and(eq(intimacy.customerId, args.customerId), eq(intimacy.therapistUserId, args.therapistUserId)),
  });
  return { exp: row?.exp ?? 0, level: row?.level ?? 0 };
}
```

> 注：`debit/credit` 的入参字段名（`txnType`/`metadata`/`idempotencyKey`）以 `apps/api/src/services/points.ts` 实际签名为准；上方 `as never` 占位类型断言在 Step 3 实现时替换为 points.ts 导出的真实入参类型（读 points.ts 顶部 `interface` 对齐字段，去掉 `as never`）。`ErrorCode.E1002_NOT_FOUND` 以 `apps/api/src/errors.ts` 实际枚举名为准。

```typescript
const ActionBody = z.object({ action_code: z.string().min(1).max(64) });

companionRoutes.post('/:therapistUserId/action', zValidator('json', ActionBody), async (c) => {
```
