# 技师橱窗带货 M09a 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 激活已有 M09a 橱窗后端骨架，补齐国家分货 / 年龄门槛 / 退款闭环 / 佣金后移结算 + 全套前端，让「平台供货→技师选品→客户下单→平台履约→送达结佣」成人用品带货闭环真正跑通。

**Architecture:** 复用现有 `shop_items`/`therapist_shop_listings`/`shop_orders` schema 与 `placeShopOrder`/`commerce.ts` 路由（已注册 `/shop`）。三表迁移 SQL 从未生成是头号 blocker，先建表。后端把"下单即结佣"拆成"下单冻结(PENDING)→送达结佣(SETTLED)"，新增退款回滚。前端从零建 admin 商品/履约页 + 客户橱窗下单 + 技师选品。纯积分支付，后台手动履约。

**Tech Stack:** Bun + Hono + Drizzle(Postgres) + Vitest(e2e 真库 loverush_test) · Next.js(apps/web 客户端 / apps/admin 后台) · 积分 `points.ts` credit/debit · `POINTS_PER_USD=100`(1 积分=1 cent)

**关键事实（已核实，勿重复踩坑）：**
- 三表 schema 在 `packages/db/src/schema/shop.ts`，**但 `migrations/` 无建表 SQL，生产库没有这三张表**。最新迁移 `0049`。
- 路由 `apps/api/src/routes/commerce.ts` 已有 `GET /shop/items`、`PUT /shop/me/listings`、`POST /shop/orders`、`GET /shop/by-therapist/:id`，已在 `index.ts:187` 注册。**但无平台商品池写接口（admin 建/改商品）**。
- 枚举 `points_txn_type`（`packages/db/src/schema/enums.ts:59-81`）已含 `SHOP_PURCHASE`/`SHOP_COMMISSION`/`REFUND`。
- `placeShopOrder`（`apps/api/src/services/shop.ts:105-218`）现状=下单即 credit 佣金即入 `therapistEarnings`。
- `shippingAddressEncrypted` **实为明文存储**（项目无真加密，字段名约定而已）。
- 前端客户端/技师端/admin **均无任何橱窗代码，100% 从零**。

```typescript
import { sql, eq, and } from 'drizzle-orm';

export async function listShopItems(
  ctx: ShopContext,
  args: { countryCode?: string; category?: string } = {},
) {
  const conds = [eq(shopItems.isActive, 1)];
  if (args.countryCode) {
    conds.push(sql`${args.countryCode} = ANY(${shopItems.countryCodes})`);
  }
  if (args.category) conds.push(eq(shopItems.category, args.category));
  return ctx.db.query.shopItems.findMany({
    where: and(...conds),
    orderBy: (t, { desc }) => [desc(t.soldCount)],
  });
}
```

```typescript
const POINTS_PER_USD = 100;

export async function settleShopOrder(ctx: ShopContext, args: { orderId: string }) {
  const order = await ctx.db.query.shopOrders.findFirst({ where: eq(shopOrders.id, args.orderId) });
  if (!order) throw HttpError.notFound(ErrorCode.E0003_RESOURCE_NOT_FOUND, 'order not found');
  if (order.commissionStatus !== 'PENDING') return order; // 幂等短路
  const commission = order.therapistCommissionPoints;
  if (commission > 0 && order.therapistUserId) {
    await credit({ db: ctx.db }, {
      userId: order.therapistUserId, type: 'SHOP_COMMISSION', amount: commission,
      description: `橱窗分成结算 · ${order.orderNo}`, relatedUserId: order.customerId,
      metadata: { shopOrderId: order.id }, idempotencyKey: `shop.commission.${order.id}`,
    });
    const cents = Math.floor((commission * 100) / POINTS_PER_USD);
    await ctx.db.insert(therapistEarnings)
      .values({ therapistUserId: order.therapistUserId, availableCents: cents, shopCommissionCents: cents })
      .onConflictDoUpdate({ target: therapistEarnings.therapistUserId, set: {
        availableCents: sql`${therapistEarnings.availableCents} + ${cents}`,
        shopCommissionCents: sql`${therapistEarnings.shopCommissionCents} + ${cents}`,
        updatedAt: new Date(),
      }});
  }
  const [updated] = await ctx.db.update(shopOrders)
    .set({ commissionStatus: 'SETTLED', status: 'delivered', deliveredAt: new Date(), updatedAt: new Date() })
    .where(eq(shopOrders.id, order.id)).returning();
  return updated;
}
```

```typescript
export async function refundShopOrder(ctx: ShopContext, args: { orderId: string }) {
  const order = await ctx.db.query.shopOrders.findFirst({ where: eq(shopOrders.id, args.orderId) });
  if (!order) throw HttpError.notFound(ErrorCode.E0003_RESOURCE_NOT_FOUND, 'order not found');
  if (order.status === 'refunded') return order; // 幂等
  // 1. 退客户积分
  await credit({ db: ctx.db }, {
    userId: order.customerId, type: 'REFUND', amount: order.totalPoints,
    description: `橱窗退款 · ${order.orderNo}`, relatedUserId: order.therapistUserId ?? undefined,
    metadata: { shopOrderId: order.id }, idempotencyKey: `shop.refund.${order.id}`,
  });
  // 2. 回补库存/销量
  await ctx.db.update(shopItems).set({
    stockQty: sql`${shopItems.stockQty} + ${order.qty}`,
    soldCount: sql`GREATEST(${shopItems.soldCount} - ${order.qty}, 0)`,
  }).where(eq(shopItems.id, order.shopItemId));
  // 3. 若已结佣，从技师扣回（积分 + cents 两账户）
  if (order.commissionStatus === 'SETTLED' && order.therapistUserId && order.therapistCommissionPoints > 0) {
    await debit({ db: ctx.db }, {
      userId: order.therapistUserId, type: 'ADJUSTMENT', amount: order.therapistCommissionPoints,
      description: `橱窗退款扣回佣金 · ${order.orderNo}`,
      metadata: { shopOrderId: order.id }, idempotencyKey: `shop.refund.clawback.${order.id}`,
      allowNegative: true, // 余额不足允许记负债，不静默吞；若 debit 无此参数则改用专门负债处理
    });
    const cents = Math.floor((order.therapistCommissionPoints * 100) / POINTS_PER_USD);
    await ctx.db.update(therapistEarnings).set({
      availableCents: sql`${therapistEarnings.availableCents} - ${cents}`,
      shopCommissionCents: sql`${therapistEarnings.shopCommissionCents} - ${cents}`,
      updatedAt: new Date(),
    }).where(eq(therapistEarnings.therapistUserId, order.therapistUserId));
  }
  // 4. 置退款态
  const [updated] = await ctx.db.update(shopOrders).set({
    status: 'refunded', commissionStatus: 'VOID', refundedAt: new Date(), updatedAt: new Date(),
  }).where(eq(shopOrders.id, order.id)).returning();
  return updated;
}
```
注：若 `debit` 不支持 `allowNegative`，改为先查技师余额，不足则只扣 earnings 并 `logger.warn` 告警（不可静默），执行时按 `points.ts` 实际签名调整。
