# 撩拨发图 Phase 3 · 前端（素材库管理 + 锁定卡解锁）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。Steps 用 `- [ ]`。
> 承接 P1/P2/P2b（chat_media 表 + 挑图/先撩后发/付费解锁后端全就绪）。

**Goal:** 让撩拨发图真正能用：①技师有「聊天素材库」管理页(传图/分级/启停)②聊天里把 `media_locked` 消息渲染成不硬软卡 → 客户解锁 → 真图出现。按转化策略(峰值/破冰/变量)。

**Architecture:** 后端加 chat_media 自助 CRUD(`/chat-media/me`)。技师端新页 `t/me/chat-media`(复用 MediaUploader purpose='chat_attachment' 传图 → POST 落库 + 分级)。聊天页加 `type='media_locked'` 渲染分支 → `LockedMediaCard`(模糊缩略图+软文案+解锁按钮→POST unlock→乐观插入真图)。

**Tech Stack:** Next15 + React + Tailwind。**窄 select；零交易词；不硬软卡复用陪聊付费质感。**

**设计来源：** `2026-06-05-撩拨发图-design.md` + 转化策略。

- [ ] **Step 3: 写路由** `apps/api/src/routes/chatMediaAdmin.ts`:
```typescript
import { Hono } from 'hono';
import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';
import { and, desc, eq } from 'drizzle-orm';
import { chatMedia } from '@loverush/db';
import { requireAuth } from '../middleware/auth';
import { getDb } from '../db';
import { HttpError } from '../middleware/errors';
import { ErrorCode } from '@loverush/types';

export const chatMediaAdminRoutes = new Hono();
chatMediaAdminRoutes.use('*', requireAuth);

const AddBody = z.object({
  url: z.string().url(), thumbnail_url: z.string().url().optional(),
  tier: z.enum(['free', 'paid']).default('free'),
  price_points: z.number().int().min(0).default(0),
  intimacy_min: z.number().int().min(0).max(4).default(0),
  weight: z.number().int().min(1).max(100).default(1),
});
const PatchBody = z.object({
  tier: z.enum(['free', 'paid']).optional(), price_points: z.number().int().min(0).optional(),
  intimacy_min: z.number().int().min(0).max(4).optional(), weight: z.number().int().min(1).max(100).optional(),
  is_active: z.number().int().min(0).max(1).optional(),
});

chatMediaAdminRoutes.get('/me', async (c) => {
  const uid = c.get('userId') as string;
  const rows = await getDb().select({
    id: chatMedia.id, url: chatMedia.url, thumbnailUrl: chatMedia.thumbnailUrl,
    tier: chatMedia.tier, pricePoints: chatMedia.pricePoints, intimacyMin: chatMedia.intimacyMin,
    weight: chatMedia.weight, isActive: chatMedia.isActive,
  }).from(chatMedia).where(eq(chatMedia.therapistUserId, uid)).orderBy(desc(chatMedia.createdAt)).limit(200);
  return c.json({ data: rows });
});

chatMediaAdminRoutes.post('/me', zValidator('json', AddBody), async (c) => {
  const uid = c.get('userId') as string;
  const b = c.req.valid('json');
  const [row] = await getDb().insert(chatMedia).values({
    therapistUserId: uid, url: b.url, thumbnailUrl: b.thumbnail_url ?? null,
    tier: b.tier, pricePoints: b.price_points, intimacyMin: b.intimacy_min, weight: b.weight,
  }).returning({ id: chatMedia.id });
  return c.json({ data: { id: row!.id } });
});

chatMediaAdminRoutes.patch('/me/:id', zValidator('json', PatchBody), async (c) => {
  const uid = c.get('userId') as string;
  const id = c.req.param('id');
  const b = c.req.valid('json');
  const set: Record<string, unknown> = {};
  if (b.tier !== undefined) set.tier = b.tier;
  if (b.price_points !== undefined) set.pricePoints = b.price_points;
  if (b.intimacy_min !== undefined) set.intimacyMin = b.intimacy_min;
  if (b.weight !== undefined) set.weight = b.weight;
  if (b.is_active !== undefined) set.isActive = b.is_active;
  const [row] = await getDb().update(chatMedia).set(set)
    .where(and(eq(chatMedia.id, id), eq(chatMedia.therapistUserId, uid))).returning({ id: chatMedia.id });
  if (!row) throw HttpError.notFound(ErrorCode.E0003_RESOURCE_NOT_FOUND, 'not found');
  return c.json({ data: { ok: true } });
});

chatMediaAdminRoutes.delete('/me/:id', async (c) => {
  const uid = c.get('userId') as string;
  const id = c.req.param('id');
  await getDb().delete(chatMedia).where(and(eq(chatMedia.id, id), eq(chatMedia.therapistUserId, uid)));
  return c.json({ data: { ok: true } });
});
```
