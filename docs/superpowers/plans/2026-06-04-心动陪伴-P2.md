companion.ts 顶部加（阈值=配置常量，待 Tony 调）：
```typescript
/** 亲密度等级阈值（exp 下界）· 0 陌生 1 熟悉 2 暧昧 3 心动 4 专属。待 Tony 调曲线。 */
export const INTIMACY_LEVEL_THRESHOLDS = [0, 50, 150, 350, 700] as const;
export function levelForExp(exp: number): number {
  let lvl = 0;
  for (let i = 0; i < INTIMACY_LEVEL_THRESHOLDS.length; i++) {
    if (exp >= INTIMACY_LEVEL_THRESHOLDS[i]!) lvl = i;
  }
  return lvl;
}
```
在 `triggerCompanionAction` 的亲密度 upsert 处：upsert 后读出最新 exp，算 `levelForExp(newExp)`，若与库中 level 不同则 `update intimacy set level=...`。简单做法：upsert 用 `returning()` 拿 exp，再单独 update level。返回值加 `level`。

- [ ] **Step 4: 跑测试通过** — `pnpm exec vitest run test/companion.e2e.test.ts`，Expected PASS

## Task 2: 付费动作触发一条 T1 分身回复

> 设计：付费动作（如 voice_whisper）发起后，"她"应回应一条更亲密的消息（Phase 2 先做文本回复，走 T1；真实声音合成留 Phase 3）。等级越高态度越黏（关系标签注入）。

- [ ] **Step 1: 在 ai_alter.ts 暴露付费回复入口**

读 ai_alter.ts 现有生成主链（`maybeReplyAsAlter`/`generateCandidate`）。新增导出 async 函数 `generateCompanionReply(ctx, { therapistUserId, customerId, actionCode, intimacyLevel })`：复用现有生成逻辑（人设+history），但
- tier 用 `resolveReplyTier({ scene: 'paid_action' })`（T1）；
- 在喂给 LLM 的 system/context 里注入一行关系标签：`关系：${LEVEL_LABEL[intimacyLevel]}`（LEVEL_LABEL = ['初识','熟悉','暧昧','心动','专属']），并注入动作上下文（"客户刚为你发起了『${actionCode}』，请用更亲密、贴近的语气回应一句"）。
- 返回 `{ text }`。
- 不写 messages 表也可（Phase 2 先返回文本，落库由 Phase 3 前端/或后续接 chat.ts）。若易接 chat.ts 写一条 her 消息则更好，但不强制。

`triggerCompanionAction` 末尾（亲密度写完后）调 `generateCompanionReply`，把返回的 `text` 放进结果 `{ ..., reply: text }`。失败不阻断计费（try/catch，reply 兜底 null）——钱已扣不能因生成失败回滚体验，记日志即可。
