# 心动陪伴（陪聊付费）· 设计文档

> 产品模块意义上 = M18。技师服务新增"陪聊"业务：技师本人或其 M06 分身陪客户聊天，
> 日常闲聊免费，想更近一步时为这段关系投入"心动值"。
> 状态：设计已与 Tony 逐项拍板（2026-06-04），待出实现计划。

## 一句话定位
不是"付费陪聊"，是**一段会升温的关系**。日常陪你不要钱；想和她更近一步时，为这段关系投入。

## 已拍板的核心决策
1. **计费机制** = 心动值体力条 + 亲密度等级（非订阅、非时长包）。
2. **消耗粒度** = 只有"亲密动作"耗心动值，**日常文字闲聊永远免费**（AI 永远免费接）。
3. **付费时刻** = 混合方向：**C 亲密度锚（常驻顶部情绪锚）+ A 流内壳（默认付费呈现）+ B 语音悄悄话（语音场景专用）**。mockup 见 `/tmp/paywall_moment_3variants`（本仓 `docs/superpowers/assets/` 可归档）。
4. **谁在聊** = 技师本人在线时本人、离线时分身无缝接管；客户视角完全替身、零 AI 标识（沿用 M06 铁律 [[loverush_m06_status]]、[[feedback_ai_stealth]]）。计费对客户无差别。

## 三层结构（地基 → 升温 → 羁绊）

### ① 地基：日常闲聊，永远免费
早安晚安、吐槽、闲扯——全免费、无限。分身主动触达引擎（已有）让"她"主动来找你。
这层唯一任务是**养关系、养习惯**。地基越免费，付费那一刻越不硬。

### ② 升温：亲密动作才耗心动值
不是每句话扣钱，是客户**显式发起**的、被情绪包装的"升温动作"。判定一条消息够不够亲密**绝不交给 AI**（会误判、易露馅、体验割裂）——只有客户主动点这些动作才计费。

| 动作 | 客户体验 | 复用现有能力 |
|---|---|---|
| 语音悄悄话 | 听"她"用声音说一段只给你的话 | M06 声音复刻 |
| 叫醒 / 哄睡 | 早安叫醒、睡前专属夜聊 | 分身 + 定时触达 |
| 今夜专属 | 今晚她只陪你、不接别人（独占感） | 分身排他锁 |
| 看看她 | 解锁独家私照 / 小视频 | paywall.unlock（现成） |
| 撩拨模式 | 开启更大胆的对话语气 | 分身 prompt 档位切换 |

定位话术：这些不是"付费功能"，是"**关系往前走一步**"。

### ③ 羁绊：亲密度等级（陌生 → 熟悉 → 暧昧 → 心动 → 专属）
越互动越亲。等级带来的**不是付费关卡，是"她"对你的态度变化**——更黏、更主动、记得你更多细节（复用 M06 记忆锚点）。
- 免费也能升级（靠时间 + 互动累积）。
- 心动值是**加速器**：解锁"专属时刻"、推进里程碑。
- **等级本身就是情绪价值，付费是助推不是闸门。**

## 心动值经济模型
- **免费额度**：日常闲聊不消耗；新人给一份"亲密动作体验券"（充分上头）。
- **恢复**：闲聊无限，不需要恢复体力；亲密动作靠充值。（不做"等明天回血"惩罚式断点。）
- **充值**：心动值包，法币计价（沿用 0027 法币 + 汇率体系；心动值作独立显示层，**避免与线下"心动金保证金"混淆**）。
- **分成**：客户充值 → 消耗亲密动作 → **技师拿大头** + 平台抽成。
  这是关键：旧结算模型里订单费走线下（[[loverush_order_flow_settlement]]），**陪聊是技师第一个真正的站内分成收入**，正好闭合"情绪价值 → 陪聊付费 → 复购 → 技师留存"飞轮（[[feedback_ai_stealth]]）。

## 成本模型与模型分层（"永远免费"如何可持续）
成本压力的根源**不是"免费"，是"免费 × Sonnet"**：M06 分身现状默认跑 T1（claude-sonnet-4-5，$3/$15 每 Mtok），免费无限闲聊跑在最贵 tier 上才是问题。

**单条回复成本**（input≈1800 / output≈80 token，含 1.3× 重生成）：

| 模型 | 单条 | 重度免费用户/月(1500条) | 普通免费用户/月(450条) |
|---|---|---|---|
| T1 Sonnet（现状） | ~$0.009 | $12.9 | $3.9 |
| **T2 Haiku（采用）** | ~$0.0023 | **$3.5** | **$1.0** |
| gpt-4o-mini（备线） | ~$0.0004 | $0.6 | $0.18 |

**核心决策（2026-06-04 拍板）：模型分层，成本跟着收入走**
- **免费闲聊 = T2 Haiku**（claude-haiku-4-5，$0.8/$4）。短回复+强人设+8 条 history 窗口下质量足够，露馅风险低。成本压到现状 1/4。
- **付费亲密动作 = T1 Sonnet（+ 声音）**。贵模型只在赚钱时用。
- 这一刀让免费成本与"免费养、付费赚"天然对齐。

**现成的天然节流**（已在代码里）：单条 ≤55 字、debounce 连发合一、history 仅 8 条（input 不膨胀）、不秒回拟人延迟（限频）、maxRegenerate≤2。

**要加的杠杆**：
1. 高频开场（早安/晚安/在线问候）半模板或最便宜模型，不必每条 LLM。
2. 主动触达限频（分身主动找客户也烧 token）。
3. 极端白嫖**软收口**：某用户当天异常高频又零付费倾向 → 她自然"今晚有点困先睡啦，明早叫你"。情绪化收尾，不破坏"免费"承诺也挡滥用。

**可持续性账**：T2 下普通免费用户 ~$1/月，一个充 $20/月 的付费用户可覆盖 ~20 个免费用户。免费层 = 获客成本，**盯住转化漏斗才是根本**。

**风险（诚实）**：
- 降 T2 的露馅风险：角色一致性对模型敏感（[[reference_llm_roleplay_reliability]]）→ **上线前必须 A/B 自测**，露馅就是这条业务生命线，质量不过关不准降。
- 转化率：M03 渗透曾仅 3.7%（[[loverush_m03_audit_2026_06_01]]）→ 付费率长期极低则免费成本累积失控，必须盯漏斗。
- 主动触达 + 声音是额外成本中心，单独控频。

## 付费时刻（不硬 = 这套设计的灵魂）
铁律（[[feedback_ai_no_sales_empathy]]）：
- **永不弹**"余额不足，请充值"。
- **不断她、不让她变冷**。她的冷暖只由真实互动驱动，**绝不由余额驱动**（"她变冷逼充值"= 操纵 = 伦理红线，坚决不做）。
- 充值用**她的口吻**自然延续（A 流内壳）：想发起亲密动作但心动值不够时，是"她"把话说一半，旁边一行轻提示"为这段心动·添点温度"。
- **零交易词**：不出现"购买 / 解锁 / 套餐 / 余额"。心动值叫"你们的心动值 / 羁绊"。

三方向如何协同：
- **C 亲密度锚**：聊天页顶部常驻细条（暧昧 ▸ 心动），做贯穿情绪锚 + 里程碑式付费叙事。
- **A 流内壳**：所有亲密动作的默认付费呈现，长在聊天流里、不打断沉浸。
- **B 语音悄悄话**：她主动发来柔化波形 + 心锁的语音，点击就地展开，专给语音场景。

## 与线下服务双向漏斗
- 陪聊养感情 →"好想见见你本人"→ 自然导流线下下单（关系推进，非硬推）。
- 线下服务后 → 分身延续关系 → 陪聊复购。
- 陪聊 = 日常维持层，线下 = 高潮层，互相喂。

## 防露馅 + 伦理红线
- 完全替身、零 AI 标识（[[feedback_ai_stealth]]、[[loverush_m06_facts_guardrail]]）。
- 不做余额驱动的情绪操纵（冷暖、已读不回、撤回逼充值一律禁止）。
- 亲密动作"深度判定"= 客户显式触发，不用 AI 判每句话。
- 分身承诺边界沿用 M06 事实护栏（时间/价格/项目不越权承诺）。

## 落地骨架（[[feedback_executable_design]]）
- **新表**
  - `companion_actions`：亲密动作目录（type / 心动值价 / 法币价 / 复用能力标记 / 启用）。
  - `intimacy`：客户 × 技师 亲密度（level / 经验值 / 记忆锚点引用 / updatedAt）。
  - 心动值账本：优先复用 `points_transaction` 加 `scene='companion'` 标记，独立显示层；或独立子账户（实现期二选一）。
- **接口**
  - `POST /companion/:therapistId/action`：发起亲密动作（校验心动值 → 扣减 → 触发分身/声音/媒体 → 写账本 + 分成）。
  - `GET /companion/:therapistId/intimacy`：亲密度 + 可发起动作 + 心动值余量。
  - `POST /companion/recharge`：充值心动值包（法币）。
- **复用**：M06 分身回复 / 声音复刻 / 主动触达 / 记忆、`paywall.unlock`、积分钱包、0027 法币 + 汇率、SSE 实时。

## 转化策略（陪聊付费 + 撩拨发图 共用 · 每个付费口子按此设计）
> Tony 2026-06-05 拍板。核心张力:全套设计「不硬/零推销感」,那靠什么让人付费?

**核心心法:不卖产品,卖「差一步」的渴望。不硬 ≠ 不引导。**
不硬 = 不说推销话术、不打断沉浸、不靠操纵冷暖逼充值。但要**精心造欲望 + 在情绪峰值给对的口子**,让客户被**自己的欲望拉过去**,不是被推过去。转化发生在「想要」的峰值,不在折扣横幅。

**六个转化杠杆(每个映射到具体付费口子)**:
1. **第一次付费=唯一命门(破冰)**:付过一次(哪怕极小)心理闸门即破,复购极易。→ 在情绪峰值给**近乎零摩擦的微付费口子**(最便宜心动值包,她刚撩完那一刻,一键完成)。**首充破冰率是唯一该死盯的指标。**
2. **变量奖励=复购引擎(老虎机)**:撩拨发图随机新图+防重=每次一次新「抽卡」,不知道下张多撩→上头;分身回复不确定撩度同理。防重+随机不只是体验,是变现引擎(Gacha/Replika 同理)。
3. **互惠+沉没成本**:她先免费给(钩子图/免费闲聊/记得你)→你欠她→付费「还」得自然;亲密度/羁绊越高投入越多→不舍得让它凉→为维持付费(Replika 付费12月留存45% vs 整体25%)。
4. **峰值微付费,非冷场推折扣**:口子放唤起峰值(她刚撩完、你正想看),阻力最小。绝不冷场弹「充值优惠」(M03 死法)。
5. **独占+身份感**:「今夜专属」「只给你看」「她记得你」→「她是我的」认同→为维持独占付费。
6. **关系进度门=软付费墙**:亲密度升级解锁更私密→付费是「陪她走到心动」非「买功能」。

**鲸鱼经济(铁律)**:这类 app 80% 收入来自 <5% 重氪。免费层做大获客池(养鲸鱼苗,所以闲聊/钩子图必须慷慨免费)+ 识别喂饱鲸鱼(更深独占/定制/无限/真人通道);不为榨 95% 不付费者破坏体验。

**诚实风险**:M03 渗透 3.7%、转化惨——美的设计 ≠ 高转化([[loverush_m03_audit_2026_06_01]])。必须:①死盯首充破冰率 ②A/B 峰值口子位置/价格/话术(同样不硬,位置差一点转化差几倍)③警惕「不硬」滑成「不引导」(欲望要造、路径要给,只是不推销)。

**落地原则**:每个付费口子(语音悄悄话/今夜专属/付费私密图/充值)实现时都要答三问——①是否在情绪峰值?②首次是否够便宜够一键(破冰)?③是否有变量奖励/独占/进度感(非纯交易)?**优先把「破冰微付费」这一个点打磨到极致,0→1 最关键,其余杠杆是放大器。**
