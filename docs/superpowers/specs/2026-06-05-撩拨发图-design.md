# 撩拨发图（技师聊天素材库）· 设计文档

> 产品意义上 = M18 子功能（陪聊延伸）。客户开口要图 → 技师分身「先撩后发」，
> 每张图是「关系往前一步」的钩子；越聊越亲，越能解锁更私密的。
> 状态：与 Tony 逐项拍板（2026-06-05），待出实现计划。

## 一句话定位
不是「发图」，是**用图勾心动的撩拨节奏**：先撩起期待，再给图当回报；图越私密越要关系/付费换。

## 已拍板核心决策
1. **商业模型** = 混合：免费几张钩子图养心动（降门槛、建关系）→ 深入/私密图走心动值付费解锁。
2. **图来源** = **独立「聊天素材库」+ 分级**（技师专为聊天撩拨准备，不挂公开主页，区别于 galleryJson）。
3. **触发** = 客户**开口要图**才发（被动·意图判定），非分身主动刷图。
4. **防重复** = 发送记录表，发过的排除，永不重发。
5. **防连发** = 按**对话轮数**冷却（≥N 轮纯文字才允许下一张），比硬时间更自然。
6. **先撩后发** = 分身先发 LLM 生成的撩拨文字（在人设里建立期待），隔一拍再发图。
7. **分级 × 亲密度联动** = 图按 intimacyMin 绑亲密度，越亲解锁越私密/越便宜，发图既是钩子又是关系进度，咬死陪聊付费飞轮（[[loverush_companion_chat_design]]）。

## 转化策略
见母 spec `2026-06-04-心动陪伴-design.md` 的「转化策略」节（陪聊付费 + 撩拨发图共用）：不卖产品卖「差一步」的渴望、破冰微付费是命门、变量奖励(随机新图+防重)=复购引擎、峰值给口子、鲸鱼经济、死盯首充破冰率。**本功能每个付费口子(付费私密图)实现时按「峰值/破冰/变量奖励」三问设计。**

## 数据模型
- **`chat_media`（聊天素材库）**：技师专属撩拨图目录。
  `{ id, therapistUserId, url, thumbnailUrl, tier: 'free'|'paid', pricePoints?, intimacyMin (默认0), weight (默认1), isActive (默认1), createdAt }`
- **`chat_media_sends`（发送记录·防重核心）**：
  `{ id, therapistUserId, customerId, mediaId, conversationId, sentAt }`
  唯一约束(therapistUserId, customerId, mediaId) → 一张图对一客户只发一次。

## 撩拨 + 发图流程（接进 M06 分身回复管线 ai_alter）
1. 客户消息进 → 分身回复管线加一道 **mediaIntent 判定**（复用现有 reply LLM 一次调用，结构化输出：`wantPhoto: bool`）。
2. 命中 wantPhoto + 冷却 OK + 有未发过的合规图（tier 允许 + intimacyMin ≤ 当前亲密度）：
   a. 分身先发**撩拨文字**（LLM 生成·非模板·建立期待，走现有拟人延迟/debounce [[loverush_m06_status]]）。
   b. 隔一拍 `pickFreshMedia(customer)` 挑一张：
      - **免费钩子图**（该客户已发 free 图 < 免费额度 N 且 tier=free）→ 直接发 `type:'image'` 消息，养心动。
      - **付费私密图**（free 额度用尽 / tier=paid / 仅高亲密度有）→ 用陪聊付费的「不硬」软卡（"这张我有点害羞…想看的话…" + 心动值解锁，[[feedback_ai_no_sales_empathy]]）→ 付了才发。
   c. 发图 → 入 `chat_media_sends` + 更新冷却锚点。
3. 冷却没到 / 已发光 → 文字挡回不发：「急什么嘛，再陪我聊会儿~」/「都给你看光啦，等我再拍新的~」（优雅·绝不重复·保神秘）。

## 防重复 + 防连发（两个硬要求的确定性方案）
- **防重**：`pickFreshMedia` = `SELECT * FROM chat_media WHERE therapistUserId=X AND isActive=1 AND intimacyMin≤lvl AND id NOT IN (SELECT mediaId FROM chat_media_sends WHERE therapistUserId=X AND customerId=Y) AND tier IN (允许档) ORDER BY random()*weight LIMIT 1`。空 → 收口话术，不重发。
- **防连发**：冷却锚 = 该会话上一张图的 message 序号/时间。规则：上一张图之后必须有 **≥N_COOLDOWN 轮纯文字往来**（默认 2）才允许下一张。未到 → 不发、文字撩回。

## 分级 × 亲密度 × 付费 × 免费额度
- `intimacyMin`：陌生(lvl0)只够到 free 钩子图；亲密度涨（陪聊付费体系）逐级解锁更私密图（可设更高 tier 图 intimacyMin=2/3）。
- 免费额度 `FREE_PHOTO_QUOTA`（每客户·默认数值待 Tony 定）：发满后 free 图也转付费 or 只剩 paid。
- 付费图复用心动值解锁（积分钱包 + 不硬软卡），技师分成同陪聊付费。

## 防露馅 + 伦理（沿用铁律）
- 撩拨是真情绪非推销话术；发不发由关系驱动不由余额逼（[[feedback_ai_no_sales_empathy]]）。
- 完全替身零标识（[[feedback_ai_stealth]]）；图是技师真人图，合规由技师自负 + 媒体审核（content_audit_records）。
- 防连发/防重本身=不廉价保神秘的产品机制（Tony 洞察）。

## 落地骨架（[[feedback_executable_design]]）
- 新表 `chat_media` + `chat_media_sends`（迁移）。
- **技师端**：聊天素材库管理页（传图走现有 media 上传 + 分级/排序/启停）。
- **后台**：素材审核 + 管理（复用媒体审核 + 可加专页）。
- **分身管线**：`mediaIntent` 判定 + `pickFreshMedia` + cooldown 检查 + 发图（`type:'image'` 消息 / 付费图心动值解锁），接进 ai_alter 回复主链。
- **复用**：M06 分身/拟人延迟、chat image 消息、心动值/亲密度/不硬软卡、媒体上传/审核、技师分成。
- **鲁棒性**：DB 查询用窄 select 不用 query.findFirst 选全表（免疫并发 schema 漂移，[[feedback_parallel_session_worktree_isolation]]）。

## 开放问题（数值·配置驱动·待 Tony 拍，不阻塞建表/逻辑）
1. 免费额度 N（每客户几张钩子图）。
2. 防连发冷却轮数 N_COOLDOWN（默认 2）。
3. 付费私密图定价（心动值）+ 分成比例。
4. 亲密度门槛 intimacyMin 各级阈值。
5. mediaIntent 判定走 LLM 结构化输出 vs 关键词+LLM 兜底（实现期定，倾向复用 reply LLM 一次调用省成本）。
