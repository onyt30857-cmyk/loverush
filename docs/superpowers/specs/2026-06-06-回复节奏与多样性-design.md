# 分身回复节奏与多样性规范 v1（M06）

> 2026-06-06 · 起因：生产 Mei×sam 对话暴露两个体验问题——①客户要照片时撩拨话术模板化复读；②回复"连着回"、节奏不像真人。
> 调研三路（当前代码 + 市场回复节奏框架 + 市场防模板化框架）后定稿。本规范界定"分身回复像不像真人"的统一标准与落地优先级。

## 1. 背景与目标

分身（M06）已有一套不差的节奏地基（见 §3 现状），但缺一套把参数对齐"真人分布"的统一规范，导致两类露馅：复读 + 喷条/节奏机械。目标是把回复的**速度、节奏、多样性**三维度系统化，对齐学术实测的真人指标，且适配 LoveRush 的**闭源 API（Anthropic/OpenAI）+ 单人轻量团队**现实。

## 2. 市场框架结论（可抄的三套）

- **Stephanie2（复旦 2026-01, arXiv 2601.05657）** — 最贴需求。延迟显式建模 `T_delay = k_think·思考字数 + k_type·回复字数 − API耗时`（实证 `k_think=0.02s/字, k_type=0.2s/字`）；**语义化主动等待**（看用户末句有无"但是/还有"等未说完信号决定接话/继续听）；实测真人 **ACMC（平均连发条数）≈1.70**、每条≈6 词。
- **Beyond Words（ACM CUI'24, arXiv 2510.08912）** — 反直觉铁律：**只加延迟/犹豫=最差**（被评机械），延迟必须配"打字-改口"才显自然；纯秒回反而比"只犹豫"好。意思：慢必须有内容上的人味配套。
- **多样性栈** — shuffle-bag 加权随机（偏向最少用过）+ repeat-distance（N 轮内不重选）+ embedding 会话级自我去重（SBERT 最近 5-10 条 cosine≥0.85 重生成）+ mood 状态机（同意图不同心情措辞天然不同）。
- **硬约束** — DRY/XTC 等最强采样层防重复**只在开源推理栈可用**，闭源 API 用不了 → 防重复重担压在**模板 shuffle-bag**（轻）+ **重生成去重**（已有 SimHash 雏形）两层。

## 4. 规范（速度 / 节奏 / 多样性 / 人格 / 情境）

| 层 | 现状 | 目标参数 | 改动点 | 优先级 |
|---|---|---|---|---|
| 速度 | 纯随机 3-9s | think+type 双项公式（0.02×思考字数+0.2×回复字数−API耗时） | `computeReplyDelayMs` | P1 |
| 分条节奏 | 最多 4 段无分布约束 | 连发条数对齐 **ACMC≈1.7**（1段60%/2段30%/3段10%），每条≈6 词 | `coalesceSegments` | **P0 ✅** |
| 防抢话 | 计时 debounce | 加语义判断：末句有未完成信号则继续等 | `schedulePendingReply` | P2 |
| 文案多样性 | 撩拨 5 条纯随机 | shuffle-bag + repeat-distance（避开最近发过的）+ 库扩到 15 | `companionMedia.generateTease` | **P0 ✅** |
| 生成多样性 | SimHash 200条 | 保留；关键场景（要图/破冰）overgenerate 多候选选最不重 | `ai_alter` 重生成 | P1 |
| 人格变化 | persona 固定 | 轻量 mood 状态机（黏人/吃醋/慵懒/调皮，随时间衰减，注入 prompt） | `buildSystemPrompt` | P1 |
| 情境 | 深夜变速 | 加"忙碌人设"分钟级延迟分级（可选） | `computeReplyDelayMs` | P2 |

## 5. P0 已实现（本次）

- **撩拨话术防复读**：`companionMedia.ts` `TEASES` 5→15 条；`generateTease(recentTexts)` 从"没说过的"里选；`runTeasePhotoFlow` 取最近 8 条分身文字（新增 `chatMedia.recentAlterTexts` 窄 select）传入。复读概率从 20%→连续不重复。
- **连发条数对齐 ACMC≈1.7**：`ai_alter.ts` 新增 `coalesceSegments`，对切好的段做概率合并（1段60%/2段30%/3段10%），接到发送循环 `coalesceSegments(splitIntoSegments(finalText))`。修掉"老是恰好喷 3 条"。
- 测试：`test/unit-reply-rhythm.test.ts`（9 绿，含分布统计 ACMC 落 1.4-1.8 + repeat-distance 防复读）；companion-media/ai-alter-history/gift e2e 16 绿不回归。

## 6. 后续（P1/P2，待排期）

- **P1**：think+type 延迟公式；mood 状态机（离散变量+衰减，注入 prompt，让同意图不同心情自然变样）；关键场景 overgenerate 多候选去重。
- **P2**：语义化主动等待（替计时 debounce）；忙碌人设分钟级延迟分级。
- **合规留口**：Beyond Words 的"打字-改口/自我修改"能显著提自然度，但涉及"装作在改口"，要不要做需 Tony 拍板（合规权衡）。
